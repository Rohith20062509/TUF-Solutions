## 📝 Problem Statement

Given a string s, write a program to invert the case of each character:

- Convert **lowercase** letters to **uppercase**
- Convert **uppercase** letters to **lowercase**
- **Leave non-alphabetic** characters unchanged

### Example 1:

**Input:** s = "javA"

**Output:** "JAVa"

**Explanation:** j → J, a → A, v → V, A → a

### Example 2:

**Input:** s = "take u forward IS Awesome"

**Output:** "TAKE U FORWARD is aWESOME"

**Explanation:** All alphabet cases inverted; spaces preserved
